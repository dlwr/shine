# 「なんかやろう」と言われたとき

こちらから作業候補を複数並べて提示する。勝手に 1 つ選んで着手しない。

候補は次の 5 軸で出す。北極星に効かないことは候補から外す理由にしない。

1. **北極星に効く施策**（CLAUDE.md の「価値と北極星」）
2. **作って面白いもの**: 価値 (1) 観る映画が自動で決まる・(3) 知られていない映画の再発見に効く機能（新しい切り口のページ・一覧・おすすめ）、見た目と体験の刷新、それ以外でも SHINE が面白くなるもの。毎回 1 つ以上出す
3. **保守性と開発速度を上げるリファクタ**
4. **パフォーマンス向上のリファクタ・実装**（応答時間・D1 の読み取り量・キャッシュ命中率・バンドル）
5. **取り下げ**: 30 日訪問の無いページ・節を消す候補（RUM で測る）。新しい切り口はなるべく既存のページの節として足し、ページ・メニュー項目を増やさない（2026-10-28 にオーナーが「ゴテゴテしてきた」）

既存の価値観（log.md の「もう出さない候補」、CLAUDE.md の「保留」）に捉われずに考える。過去に却下した案でも、状況が変わったなら理由を添えて出してよい。運用タスク（速報の準備・dry-run・本番確認）だけを並べるのは物足りない。

## 手順

1. [log.md](log.md) を読む。前回までの候補・済んだもの・測った前提・罠が書いてある
2. `pnpm scrapers survey` を流す。本番 TTFB・D1 の読み取り量と上位 5 文・北極星・先行指標・大きいファイル・main の GitHub Actions の最新結果が一度に出る。手で curl や wc を並べない
   - `.dev.vars` / `.env` のトークン（D1 proxy・Cloudflare の GraphQL）が無い環境（クラウドのセッションなど）では survey が流せない。そのときは流せなかったと書き、log.md の「残っている候補」と、コードを読んで分かることから出す。測っていない数値を書かない
3. main の CI が赤ならそれを最優先の候補にする（survey の Actions 欄で見る。`gh run list --branch` は古い run を返すことがある）
4. 候補は「推し＋理由一言」で短く。締め切りのある候補は先頭に出し、選ばれなくても報告の末尾に一言残す。時期依存の運用タスクは別枠で末尾に添える
   - **候補の一覧はターンの最後のメッセージに書き、そこでターンを終える**。`wrap_up` に質問とボタンを付けて終えない（付けると最後の本文が出せず、ツール呼び出しの合間に書いた本文は見えない。3 回やらかした）。`wrap_up` は recap だけで呼び、その後の締めの本文に候補を並べる
5. 複数選ばれたら 1 候補 1 PR。同じファイルを触る PR は、先のものがマージされてから次のブランチを切る
6. 終わったら log.md の「もう出さない候補」「測って分かった前提」「踏んだ罠」「残っている候補」を更新し、その回の PR に含めてコミットする。回ごとの経過は書かない（やった PR は git 履歴で追える）。200 行以内に保つ

## 候補を書く前の確認

- **数値は log.md から写さず、その場で測る**（古い値を写して選ばれてから前提が崩れたことがある）
- **北極星の候補は、既にあるものを確かめてから書く**（実装済みの月替わり投稿・ひとこと投稿・`/monthly` を新案として出して選ばれたことがある。ログの見出しを写さず中身を確かめる）
- **入口の候補を出す前に RUM を `refererHost`・`userAgentOS`・`date` で割り、`/admin` を開いている端末のセッション（持ち主）を除いて数える**
- **「テストを厚くする」候補はカバレッジを測り、既存のテストを読んでから出す**

## 選ばれやすいもの

- 北極星は小さく具体的なもの（帯の一行・`/now`・空状態・予告）
- デザインは名画座の番組表の方向の中なら大きく刷新してよい。375px の本番スクショで見つけた崩れ・順番の問題も出す
- 締め切りものと「測るだけ」の候補は選ばれにくい
- 「ログからなんか出して」は、新規を捻り出さず「残っている候補」から出せという意味

## 選ばれた後

- ファイル分割・型の整理のような機械的なリファクタは Opus に任せる。候補出しと計測・調査は Fable のままでよい。Fable のセッションで選ばれたら、着手せずに `/model opus` への切り替えを促すか、望まれれば `Agent` を `model: "opus"` で起動して任せる
